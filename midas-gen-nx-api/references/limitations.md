# 限制、未核验项与常见混淆

本包是 **资料受限、待实机验证的初版**，不是完整的 Gen API 成品。

- **未在真实 MIDAS Gen NX 或经典 Gen 上实测。**
- **不要把 Gen NX 当成经典 Gen。** 经典 GEN 产品页 FAQ 在 2026-11-18（Asia/Shanghai） 查阅时仍写：新的 GEN API 正在开发，预期 2025 年以 Web REST 形式发布。本技能只覆盖已文档化的 GEN NX。
- **没有** 已读取正文的 Gen 专用字段手册。本地手册是 Civil NX；wolai《midas Gen API 使用手册》只有标题，正文未加载。
- 官方 Python 简单梁例与本地 Civil NX 节点/单元等示例明确来自 Civil NX，只作 NX 共享形状的旁证。**未逐字段核验前不得在 Gen NX 中执行这些写入。** 仅声明来源不够。资料不足时只给草案和验证步骤。
- 楼层/设计/建筑抗震抗风等官方目录项只是「优先在 Gen NX 接口页核对」的候选，不是已核验字段表。
- 移动荷载、钢束、波浪荷载、桥梁专项等默认不属于本技能支持范围。
- 官方标注 Hyper-S only 或 CIVIL NX JP Version only 的项，不是 Gen NX 默认能力。
- 禁止保存真实密钥、调用付费第三方 API 或把模型传到其他服务。
- `/doc/SAVE` 只保存当前文件，不等于备份；需要备份时应保留独立的原始模型副本。`/doc/SAVEAS` 会切换当前文件，路径和覆盖范围必须明确。
- 404 应同时检查连接状态、Base URL 和路由/方法，不能一概解释为未连接。本地手册对 404 的表述只是原因之一。
