# 结构力学出图规范与 Canvas 渲染器 (mechanics-diagram-renderer)

## 何时使用
- 用 Canvas / SVG 绘制内力图、结构简图、支座图例
- 排查"弯矩图画反了 / 画在受压侧了 / 抛物线不见了"
- 实现世界坐标到屏幕的视口变换、自适应缩放

## 随附文件
| 文件 | 用途 |
| --- | --- |
| `templates/viewport.ts` | 视口拟合、坐标映射、比例尺、devicePixelRatio 处理 |
| `templates/canvas_renderer.ts` | BMD/SFD/AFD 绘制、支座与节点图元、数值标注 |

内力采样数据由 `matrix-stiffness-2d/scripts/member_diagram.ts` 提供。

## 1. 弯矩图 (BMD) 强制规范

- **必须画在杆件纤维受拉侧**。
- **严禁标注正负号**——受拉侧的位置本身已表达了受力的物理本质。数值只写绝对值。
- **线型**：垂直于杆轴的密排细线（阴影线）或半透明色块填充。
- **必须画出跨间抛物线**。

### ⚠️ 最常见的两个错误

**错误一：把两端弯矩连直线。**
直接刚度法只解出杆端力。跨间弯矩必须叠加荷载特解，距 i 端 $x$ 处：

$$
M(x) = -M_i + V_i x - \frac{q x^2}{2}
$$

线性项 $-M_i + V_i x$ 是两端弯矩的连线，$-qx^2/2$ 才是那条抛物线。漏掉它，满跨均布荷载下跨中会少掉 $qL^2/8$。

**错误二：把像素长度代进力学公式。**
`p2.x - p1.x` 是**像素**，不是杆长。抛物线纵标必须先用**物理杆长**算出 $M(x)$（单位 N·m），再乘比例尺换成像素。

## 2. 受拉侧方向的判定（一条规则覆盖所有杆件倾角）

设世界坐标下 $c = \Delta x / L$，$s = \Delta y / L$（由节点 i 指向节点 j）。约定 $M$ 以**下侧受拉为正**（局部 $-y$ 侧受拉）。则：

> **弯矩纵标在屏幕上的偏移方向 = $(s,\ c)$，偏移量 = $M \times$ 比例尺。**

推导：世界方向向量 $(d_x, d_y)$ 映射到屏幕是 $(d_x, -d_y)$（Y 轴翻转）；局部 $-y$ 轴的世界方向是 $(s, -c)$，映射到屏幕即 $(s, c)$。

无需对水平梁 / 竖直柱 / 斜杆分情况讨论：
- 水平梁（$c=1, s=0$）：正弯矩画在杆下方 ✓
- 竖直柱（$c=0, s=1$，i 端在下）：正弯矩画在杆右侧 ✓

**关于杆件编号方向**：颠倒 i / j 会同时反转 $M$ 的符号和局部 $-y$ 的方向，两次反号相互抵消，**图形的物理位置不变**。所以不必强求"柱子一律自下而上编号"。

**剪力图 / 轴力图**用相反的法线方向 $(-s, -c)$，即正值画在局部 $+y$ 侧（水平梁上方）。

---

## 3. 剪力图 (SFD) 与轴力图 (AFD)

- **必须标明正负号**。
- 剪力正负：使微元顺时针转动为正。
- 轴力正负：受拉为正，受压为负。
- 图形画在杆轴基准线的法线方向上，正值在局部 $+y$ 侧。

---

## 4. 支座与节点符号规范

| 图元 | 画法 |
| --- | --- |
| 固定铰支座 | 尖端指向节点的三角形 + 接地标线 + 45° 剖面线 |
| 活动铰支座 | 三角形 + 底部滚轴（两个空心小圆）+ 接地剖面线 |
| 固定端支座 | 垂直于杆端的粗实线基底 + 45° 均匀剖面线 |
| 刚结点 | 杆端交汇处直接连接，或加粗实心点 |
| 铰结点 | 空心白色小圆圈，半径 $4\sim6\ \text{px}$ |

支座图元尺寸用**固定像素**，不随视口缩放（否则放大后支座会变成巨型三角形）。支座方向用一个绕节点的旋转角控制，默认支座在节点下方。

## 5. 坐标映射

$$
x_{screen} = (x_{world} - x_{min}) \cdot \text{scale} + \text{offsetX}
$$
$$
y_{screen} = \text{canvasHeight} - \left[ (y_{world} - y_{min}) \cdot \text{scale} + \text{offsetY} \right]
$$

三条硬性要求：

1. **X 与 Y 必须共用同一个 scale**。分别取比例会把结构拉伸变形，斜杆角度全错、正交性丢失。
2. **Y 轴必须翻转**（力学坐标 Y 向上，Canvas Y 向下）。
3. **必须处理 `devicePixelRatio`**：`canvas.width = cssWidth * dpr` 并 `ctx.setTransform(dpr,0,0,dpr,0,0)`，否则高分屏上所有线条发虚。

**自适应缩放**：$\text{scale} = \min\left(\frac{W - 2p}{x_{max}-x_{min}},\ \frac{H - 2p}{y_{max}-y_{min}}\right)$，再用 offset 居中。
- 边距 $p$ 要同时容纳支座图元和内力图外伸量，建议 $\ge 60\ \text{px}$。
- 连续梁的 $y$ 跨度为 0，该方向必须跳过，不能除零。

**内力图比例尺**独立于几何比例尺：`scale = 目标像素高度 / 全模型最大内力绝对值`。同类内力图**必须全模型统一比例**，否则各杆之间的大小关系失真。

---

## 6. 文字标注
- 文字**永远水平书写**，不随杆件旋转——竖杆和倾角超过 90° 的斜杆上会出现倒置文字。
- 数值加半透明白底衬垫，避免压在阴影线上看不清。
- 展示层才把 N / N·m 换算成 kN / kN·m，计算层始终用 SI 基本单位。

## 7. 出图前自检清单
- [ ] 弯矩图在受拉侧，且**没有**正负号
- [ ] 跨间抛物线存在，跨中纵标包含 $qL^2/8$
- [ ] 采样点包含剪力零点（弯矩极值截面）
- [ ] 剪力图、轴力图**有**正负号
- [ ] X/Y 共用同一 scale，斜杆角度正确
- [ ] devicePixelRatio 已处理
- [ ] 竖杆上的标注文字未倒置
- [ ] 支座图元尺寸不随缩放变化
