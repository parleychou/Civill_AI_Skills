# 结构力学经典基准题库与自动化验证 (structure-benchmark-verifier)

## 何时使用
- 改完求解器算法、重构代码、调整符号约定之后（**每次都要跑**）
- 新增荷载类型、单元类型、边界条件之后
- 接手一份来路不明的求解器，先跑一遍确认它是否可信

## 随附文件
| 文件 | 用途 |
| --- | --- |
| `benchmarks/standard_cases.json` | 6 个算例的**完整可运行模型** + 解析解 + 逐项容差 |
| `scripts/run_benchmarks.ts` | 回归运行器，全通过退出码 0，否则 1 |

```bash
node --experimental-strip-types skills/structure-benchmark-verifier/scripts/run_benchmarks.ts
```

求解器不在默认位置时，改运行器顶部两行 `import` 路径即可（需导出同名同签名的函数）。

---

## 两类检查

### 1. 解析解比对（需要闭式解）
逐项比对位移、反力、杆端力、指定截面内力与弯矩极值。

### 2. 整体静力平衡（不需要闭式解，每个算例自动执行）

$$
\sum F_x = 0 \qquad \sum F_y = 0 \qquad \sum M_O = 0
$$

反力 + 节点荷载 + 杆间均布荷载的合力必须归零，残差阈值取荷载量级的 $10^{-9}$。

**这项检查比解析解比对更值得先做**：它不需要任何参考答案，对任意模型都成立，能抓住绝大部分装配、坐标转换、固端力符号错误。任何自研模型都应该挂上这个检查。

## 标准基准案例库

单位统一为 SI 基本单位（m / N / N·m / Pa）。约定：$M$ 下侧受拉为正，轴力受拉为正。

| ID | 算例 | 关键解析解 |
| --- | --- | --- |
| CASE-01 | 简支梁满跨均布 $L=6$, $q=10\,\text{kN/m}$ | $M_{mid} = qL^2/8 = 45\ \text{kN·m}$；$V_A = qL/2 = 30\ \text{kN}$；$w_{mid} = 5qL^4/384EI = 8.4375\ \text{mm}$ |
| CASE-02 | 悬臂梁端部集中力 $L=4$, $P=20\,\text{kN}$ | $M_{root} = -PL = -80\ \text{kN·m}$（上侧受拉）；$w_{tip} = PL^3/3EI = 21.3333\ \text{mm}$；$\theta_{tip} = PL^2/2EI$ |
| CASE-03 | 两跨等跨连续梁 $L=6+6$, $q=10\,\text{kN/m}$ | $M_B = -qL^2/8 = -45\ \text{kN·m}$；$M_{span} = 9qL^2/128 = 25.3125\ \text{kN·m}$ @ $3L/8$；$R_A=R_C=3qL/8$，$R_B=5qL/4$ |
| CASE-04 | 单跨门式刚架（固定支座）$h=4$, $L=6$, $q=10\,\text{kN/m}$ | 柱底 $M = 11.25\ \text{kN·m}$；柱顶/梁端 $M = 22.5\ \text{kN·m}$；跨中 $M = 22.5\ \text{kN·m}$；$H = 8.4375\ \text{kN}$ |
| CASE-05 | 一端固定一端铰支梁（杆端弯矩释放）$L=6$, $q=10\,\text{kN/m}$ | $M_{fix} = -qL^2/8$；释放端弯矩严格为 0；$R_{fix}=5qL/8$，$R_{pin}=3qL/8$；$M_{span}=9qL^2/128$ @ $5L/8$ |
| CASE-06 | 三杆平面桁架（全铰接），下弦跨度 4，顶点 (2,3)，顶点 10 kN 向下 | 斜杆轴力 $-P/(2\sin\theta) = -6.00925\ \text{kN}$；下弦 $+3.33333\ \text{kN}$；杆端弯矩恒为 0 |

CASE-05 与 CASE-06 专门用于校核**杆端弯矩释放的静力凝聚**是否正确——这是最容易写错、又最不容易被梁类算例发现的部分。

## 容差不是一个数字

宣称"全部误差 < 0.01%"是不成立的。不同量的可达精度本来就不同：

| 算例类型 | 相对容差 | 原因 |
| --- | --- | --- |
| CASE-01/02/03/05/06 的位移、反力、内力 | $10^{-9}$ | 欧拉-伯努利梁单元在节点处是**精确解**，跨间内力由解析式回代，理论上只有浮点误差 |
| 端部弯矩为 0、$\sum F_x = 0$ 一类的零值 | 绝对容差 $10^{-6}$ | 零值不能算相对误差 |
| CASE-04 门式刚架 | $10^{-2}$（1%） | 见下 |

**CASE-04 为什么放宽到 1%**：它的解析解由转角位移方程导出，前提是**忽略轴向变形**；求解器计入梁的轴向压缩后结果相差约 0.5%。把 $A$ 从 $0.01$ 增大到 $1.0\ \text{m}^2$ 重跑，误差会收敛到 0.01% 以内——这可以用来确认偏差确实来自轴向变形假设，而不是算法错误。遇到刚架类算例对不上时，先做这个实验再怀疑代码。

---

## 网格划分要求

- 梁单元在**节点处**位移精确，跨间是三次插值。要校核**跨中挠度，跨中必须有节点**（CASE-01 因此分成 2 个单元）。
- 要校核**跨间弯矩极值**则不必加节点——用 $M(x) = -M_i + V_i x - qx^2/2$ 解析求得，精度不损失。但 CASE-03 仍在 $3L/8$ 处设了节点，便于同时直接读取节点结果。

---

## 扩展题库时的要求

新增算例必须同时给出：
1. **完整可运行模型**（nodes / elements / loads），而不只是几个标量答案——只有标量的题库无法自动化。
2. **解析解出处或推导**（填在 `formula` 字段）。
3. **该量对应的容差**，以及容差为什么是这个量级（若非 $10^{-9}$，填 `toleranceNote`）。

## 自检清单
- [ ] 6 个算例全部通过，退出码为 0
- [ ] 整体平衡检查无残差告警
- [ ] 故意改错一个系数（例如把固端弯矩 $qL^2/12$ 写成 $qL^2/10$），确认套件**确实会失败**——不会失败的测试没有价值
- [ ] 新增算例已附模型、解析解出处与容差理由
